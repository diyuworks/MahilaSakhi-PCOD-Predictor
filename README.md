# 🌸 MahilaSakhi – AI Powered PCOD Risk Analyzer

MahilaSakhi is an AI-powered women's health assistant that predicts the risk of **Polycystic Ovary Syndrome (PCOD)** using Machine Learning and provides personalized health insights through an interactive dashboard.

The system combines **Machine Learning, Data Visualization, and AI-driven health guidance** to help users understand potential PCOD indicators and improve lifestyle habits.

---

## 🚀 Features

* 🧠 **PCOD Risk Prediction**

  * Machine learning model trained on real PCOS dataset
  * Predicts PCOD risk based on health indicators

* 📊 **Health Indicator Visualization**

  * Interactive bar chart showing user health parameters
  * Built using Chart.js

* 🤖 **AI PCOD Assistant**

  * Simple chatbot to answer PCOD-related health questions
  * Provides lifestyle guidance

* 🥗 **Diet Recommendation System**

  * Displays recommended diet plan for high-risk users

* 💡 **AI Health Recommendations**

  * Lifestyle suggestions based on user inputs

* 🎨 **Modern Dashboard UI**

  * Clean React interface
  * Responsive layout
  * Health insights displayed clearly

## 📊 Input Health Indicators

The prediction model uses the following features:

* Age
* Weight
* BMI
* Weight Gain
* Cycle Irregularity
* Hair Growth
* Pimples / Acne
* Skin Darkening
* FSH Hormone Level
* Exercise / Lifestyle Indicator

## ⚙️ How to Run the Project

### 1️⃣ Clone the repository

```
git clone https://github.com/YOUR_USERNAME/MahilaSakhi-PCOD-Predictor.git
cd MahilaSakhi-PCOD-Predictor
```

---

### 2️⃣ Start Backend (Flask)

```
cd backend
python app.py
```

Backend runs on:

```
http://127.0.0.1:5000
```

---

### 3️⃣ Start Frontend (React)

```
cd frontend
npm install
npm start
```

Frontend runs on:

```
http://localhost:3000
```
